# 🚀 Guia Rápido - Scripts de Instalação

## 📌 O que você precisa fazer

### Primeiro Acesso (Instalação)

1. **Clique duas vezes em `run.bat`**
2. **Digite:** `install`
3. **Deixe rodar** (pode levar 15-30 minutos)
4. **Acesse:** http://localhost:3000

```
C:\SistemaEmprestimos\scripts\run.bat
    └─> Digitar: install
        └─> Deixar rodar
            └─> Abrir browser em http://localhost:3000
```

### Uso Diário

- **Iniciar:** `run.bat` → `manage` → Opção 1
- **Parar:** `run.bat` → `manage` → Opção 2
- **Status:** `run.bat` → `manage` → Opção 4
- **Acessar:** `run.bat` → `manage` → Opção 5, 6 ou 7

### Atualizar Sistema

1. **Clique em `run.bat`**
2. **Digite:** `update`
3. **Deixe rodar** (5-15 minutos)

### Desinstalar

1. **Clique em `run.bat`**
2. **Digite:** `uninstall`
3. **Confirme** com "S"

## 🆘 Problemas Comuns

### "Acesso Negado"
→ Clique com botão direito em `run.bat`  
→ Escolha "Executar como administrador"

### "Docker não encontrado"
→ Instale Docker de: https://www.docker.com/products/docker-desktop

### "Porta já em uso"
→ Abra gerenciador: `run.bat` → `manage`  
→ Reinicie serviços: Opção 3

### Mais problemas?
→ Veja `README.md` na seção "Solução de Problemas"
